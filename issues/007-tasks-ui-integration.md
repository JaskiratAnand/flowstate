Implement `TodoList.svelte` and `TodoItem.svelte` with `svelte-dnd-action`. Connect directly to storage to read, add, update, and reorder tasks.

## Acceptance criteria
- [ ] User can add, edit, and delete tasks.
- [ ] User can check off tasks.
- [ ] User can assign a category tag.
- [ ] User can drag to reorder tasks.
- [ ] Changes instantly sync with `chrome.storage.local`.
