# Security Policy

## Supported Versions

We release security patches for the latest version of **FlowState**. We encourage all users to keep their extension updated to the latest release available on the browser web stores or GitHub Releases.

| Version | Supported          |
| ------- | ------------------ |
| 0.6.x   | :white_check_mark: |
| < 0.6.0 | :x:                |

## Reporting a Vulnerability

The FlowState team takes privacy and security seriously. FlowState operates strictly locally using standard Web Extension APIs (`browser.storage.local`, `declarativeNetRequest`) with zero remote tracking or telemetry.

If you discover a potential security vulnerability, please follow responsible disclosure guidelines:

1. **Do NOT open a public GitHub issue** for security vulnerabilities.
2. Email details of the vulnerability to the maintainers or report it privately through GitHub Security Advisory disclosures on the repository.
3. Please include:
   - A detailed description of the issue.
   - Steps to reproduce or proof-of-concept code.
   - Impact assessment (e.g. storage access, permission scope, domain bypass).

## What to Expect

- **Acknowledgment:** We will acknowledge receipt of your report within 48 hours.
- **Assessment:** We will investigate and confirm the report within 5 business days.
- **Fix & Release:** Confirmed vulnerabilities will be patched promptly and released in a patch update.
