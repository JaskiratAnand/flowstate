# FlowState

FlowState is a tactile, sensory-focused Pomodoro and Todo browser extension that grounds digital work in analog warmth.

## Language

**Focus Session**:
A timed deep work block where distracting sites are blocked by the Focus Shield.
_Avoid_: Work block, focus block, Pomodoro session

**Break Session**:
A timed period of rest (either a short break or a long break) following a Focus Session.
_Avoid_: Rest session, downtime

**Focus Shield**:
The site blocking system that restricts access to distracting domains during an active Focus Session.
_Avoid_: Blocker, site blocker, website filter

**Bypass**:
A temporary, timed permission granted to access a blocked domain under the Focus Shield.
_Avoid_: Whitelist, temporary allowance

## Example Dialogue

**Developer**: "How does the Focus Shield know when to block a domain?"
**Domain Expert**: "It checks if there is an active Focus Session. If a Focus Session is running, the Focus Shield enforces the rules. If the user needs to access a blocked site, they can request a temporary Bypass by completing a mindfulness challenge."
